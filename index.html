Frequently Asked Questions

Everything you need to know about our modpacks.

Download the `.zip` file from the provided links. If you are using PojavLauncher or similar on Android, extract the files directly into your `.minecraft` directory, replacing existing config and mods folders. Ensure you have the matching Fabric loader installed first!
Each modpack card specifies the exact Fabric Loader version needed (e.g., 0.19.2, 0.16.14, 0.8.14). It is crucial to use the exact version listed to prevent game crashes.
We highly recommend the "Modpack Sodium" (MC 1.21) or specifically checking descriptions for Helio G95 tested packs. These are highly optimized to reduce rendering overhead.
Root is NOT required to play Minecraft or use these modpacks. However, some performance metrics (like 170+ FPS) were achieved on rooted devices running custom kernel performance tweaks alongside the modpack.
